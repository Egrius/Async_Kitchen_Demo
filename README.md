# 🍜 AsyncKitchen

Учебный проект для отработки связки `CompletableFuture` с пулами потоков.

## 📃 Описание

Симуляция работы кухни в ресторане. Заказы обрабатываются асинхронно: разные типы блюд готовятся на разных пулах потоков (печи, напитки, десерты). 
Реализована логика повторной готовки для пиццы, если она подгорела (для этого используется случайный шанс), система делает до 2 дополнительных попыток.

## 🔧 Технологии

- Java 21
- CompletableFuture (асинхронные цепочки)
- ExecutorService (пулы потоков)
- ScheduledExecutorService (периодическая обработка очереди)

## 🎇 Ключевые фичи

- **Асинхронная готовка** — каждое блюдо готовится в своём пуле (печи, напитки, десерты)
- **Retry с ограничением** — для пиццы реализована логика повторных попыток при "подгорании"
- **Очередь заказов** — заказы поступают в очередь и обрабатываются с заданной периодичностью
- **Обработка ошибок** — `exceptionally` и `exceptionallyCompose` для грациозного падения
- **Graceful shutdown** — корректное завершение всех пулов

## 📙 Что дальше (планируется)

- Реализовать таймауты на готовку

## 🚀 Как запустить

1. Клонировать репозиторий
2. Собрать: `mvn clean package`
3. Запустить: `java -jar target/async-kitchen-1.0.jar`
